# VoxX — Инклюзивный Помощник (Web Platform)

**VoxX** — веб-приложение на базе Streamlit для людей с нарушениями слуха, зрения и речи.  
Проект ориентирован на максимальную доступность (Accessibility/a11y), адаптивный интерфейс, работу в тёмном и высококонтрастном режимах, а также оффлайн-функции распознавания.

## 🚀 Запуск приложения

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Запуск приложения VoxX
streamlit run app.py
```

## 💡 Функциональные возможности

1. **Распознавание жестов (`2_Жесты.py`)**: Веб-камера + MediaPipe для интерпретации жестов в реальном времени.
2. **Ассистент слуха (`3_Слух.py`)**: Субтитры в реальном времени (Speech-to-Text) и визуальный индикатор шума.
3. **Ассистент зрения (`4_Зрение.py`)**: Распознавание текста на изображениях (OCR) и голосовое озвучивание (TTS).
4. **Универсальная коммуникация (`5_Универсальный.py`)**: Карточки быстрых фраз с крупными кнопками (AAC) и экстренный сигнал SOS.
5. **Настройки доступности (`6_Настройки.py`)**: Регулировка масштаба шрифта, контрастности и скорости речи.
